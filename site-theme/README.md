# Moon local Astro theme snapshot

This directory is a repository-owned snapshot of the current Astro presentation layer generated by isite.

- Source generator: yihong0618/isite
- Pinned source commit: 123a35e42fcd68b3c128c59b9a38b6ba91219533
- Snapshot branch: theme-localization-test
- Purpose: preserve the current appearance before any redesign or workflow switch.

The files under `src/` are intended to be copied into the generated `output/` project after isite generates its content and before Astro builds.

This is a backup only. The production workflow is not changed by this snapshot. Do not edit the production workflow until the snapshot has been checked and a test build succeeds.

Files deliberately not copied here because they are generated configuration/data or runtime support rather than presentation:
- `src/content.config.ts`
- `src/lib/site.ts`
- `src/lib/urls.ts`
- `src/lib/image-optimizer.mjs`
- `src/pages/rss.xml.js`
- `package.json`, `astro.config.mjs`, `tsconfig.json`

These remain generated by the pinned isite version to preserve content schema, site settings, URL handling, image optimization, RSS, and dependencies.
